# Pi 1.2.0 升级

2026-10-14：桌面依赖从 `@earendil-works/pi-coding-agent@1.0.0` 精确升级到
`1.2.0`，项目锁文件和桌面运行时使用同一版本。Pi 包源码没有修改。

## 兼容性处理

- Azure provider 从 `azure-openai-responses` 迁移到 `azure`。在 SDK 读取前
  迁移全局 auth/models/settings，以及受信任项目的 settings；更新默认
  provider、模型筛选和模型思考等级。保留新 Azure 配置的优先级、文件
  权限、配置文件符号链接和其他设置，原子写入；迁移重复执行不会再次改写。无效 JSON 留给
  Pi 的原始诊断，不改动会话文件。
- 主题校验从 `theme-json.js` 改接 `theme-schema.js`。快捷键使用 Pi 的原始
  配置迁移与校验，过滤 `$schema` 元数据和无效键值。
- MCP 的 `/mcp login` 和管理器统一使用原生组件映射；保留 URL、复制、
  手动回调、取消、token 保存和重载清理。在重载开始时提前终止旧桌面
  生命周期，避免新版登录先结束、调用却误报成功的竞态。
- 桥接的固定版本保护更新为 1.2.0；增加 `Terminal.setProgramStatus`。
  SDK 导出保持原始身份：462 个声明导出、156 个运行时导出、38 个公开
  构造函数、16 个声明静态成员（15 个运行时静态成员）。
- `before_agent_start` 直接沿用新版 user/custom 联合事件和启动繁忙状态；
  仅处理用户 prompt 的测试扩展显式检查 `messageType`。

## 桌面界面映射

| 上游变化                 | 桌面行为                                                                                                                                                                          |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 运行状态上报             | 使用原始 `ProgramStatusReporter`，标题栏显示执行、压缩、重试、等待确认/输入/登录、完成和失败。取消回到 idle；桌面与窄窗口均可见。标准对话框、原生自定义界面和认证有独立阻塞来源。 |
| 工具执行耗时             | 传递 `durationMs` 到原生工具渲染上下文；工具卡片显示实际耗时，保存和重新打开会话后保留。codemode 的原生 Elapsed/Took 输出同样映射。旧记录未存耗时则不补造。                       |
| 通用工具渲染器           | 调用扩展的 `registerToolRenderer` 解析链，支持尚未注册/恢复中的工具。按 SDK 会话、工具定义和扩展加载代缓存结果，避免解析器返回新函数时反复重建桌面控件。未注册工具回退沿用原生调用/结果预览，支持折叠和逐条展开。 |
| 输出边距                 | `outputPad` 传递给工具、Shell、技能调用、压缩/分支摘要以及自定义消息/条目；设置变化应用到保留的原生组件。                                                                         |
| codemode 图片            | 原生 `tools.read()` 图片结果和 `image()` 输出进入桌面图片区域；可展开预览，生成图片保存文件路径沿用 SDK 行为。                                                                    |
| MCP 项目覆盖与实时管理   | `.pi/mcp.json` 可覆盖全局 enabled/exposure/toolExposure；原生管理器及异步连接界面直接走通用组件桥接。桌面设置页显示继承的全局服务器，支持项目启停、工具可见性及恢复全局配置；合并、默认值移除和写入使用 Pi 原生配置函数。 |
| Fullscreen 对话滚动键    | 原生 `tui.altScreen.top/bottom` 操作通知桌面主对话滚到顶部/底部。默认 Ctrl+Home/End 与重载后的自定义键位均生效，保留编辑器光标和原生输入/弹窗优先级；到顶部停止跟随，到底部恢复跟随。 |
| 新模型与 OpenRouter 列表 | 模型目录继续使用原始 ModelRuntime，包括 Haiku 5.5、按 Key 获取的 OpenRouter 列表与离线缓存。分类与图片 API 保留 Node SDK/模型操作入口。                                           |

Nix 安装、SSH 剪贴板和终端私有显示协议沿用 Pi；桌面本地剪贴板、文件
预览和控件采用已有的原生桌面路径。

## 追加界面复核与补齐

对剩余 1.0.0 → 1.2.0 界面条目追加复核发现两处差异，现已补齐：

- **账号授权 URL 复制（1.0.1）**：设置页的 provider 登录增加复制按钮，
  `app.message.copy` 使用 Pi 加载的配置和原始键位匹配结果，默认 Ctrl+X，
  支持重映射与禁用快捷键。登录快捷键优先于桌面快捷键；按钮在登录弹窗
  打开时也可操作。后端按授权 ID 复制当前流程的 URL，完成、取消、重载
  后旧请求失效；手动回调输入与选区保留。成功/失败反馈使用 Pi 主题颜色，
  可从复制失败继续重试。MCP 登录保留原生 `AuthUrlComponent` 路径。
- **自定义编辑器内嵌压缩指示器配色（1.2.0）**：桥接类型和原生构造
  补入 `colorFn`，内嵌执行/压缩指示器按 Pi 使用当前编辑器边框色，没有
  边框色时使用当前思考等级色。独立指示器保留原生默认颜色。映射原生
  CustomEditor 内嵌边框提示到 DOM，保留编辑控件和扩展自定义绘制；状态
  结束时清除。原生状态构造放入当前 Pi 键位上下文，取消提示包含正确键位。

符号快捷键回归还发现浏览器的 Kitty 编码没有提供 Shift 产生的符号信息。
现在同时传递该字段，`ctrl++` 等逻辑符号键可被 Pi 1.2.0 原始解析器匹配，
包括按下/释放阶段。

同轮确认没有遗漏的行为：codemode 执行中 Elapsed 按秒刷新、完成后
Took 使用实际执行耗时；FullScreen 浮动覆盖层保持焦点时，在主对话区域
使用鼠标滚轮可滚动；会话切换后浏览器文本选区清空。以上在 1440px 和
390px 验证。初次滚轮诊断误命中对话导航覆盖区域，改为实际对话正文后
验证通过；异步 custom 工厂的全屏 modal 背景遮罩与浮动覆盖层分别核对。
