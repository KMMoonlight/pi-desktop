# v0.1.7 输入延迟验证

2026-10-12，macOS 原生 Tauri 发布模式，Node 22.23.2。隔离配置使用约 13.19 MB 的真实长会话副本、模型和外观配置，凭据为占位值；无模型请求。诊断代码及私有会话内容不进入版本。

## 原因与同进程对照

每键创建、挂载、删除隐藏 textarea，读取 live computed style 与后续几何尺寸，触发两次整页布局，各约 88–89 ms。保持同一窗口、会话和配置，仅关闭测高后，18 字延迟从 176–188 ms 降到 1–14 ms。最终实现保留自动测高，复用隔离镜像并先读后写。

修复后第一组 18 字为 1–22 ms；最终复测 18 字为 2–15 ms。快速输入 156 字无丢字，时间戳至可见帧中位 10 ms、p95 22 ms、最大 25 ms；最终输入队列清空、无脚本错误。后台刷新最大帧间隔仍达 186–189 ms，因此不能把单字延迟等同于全界面无卡顿。

## 切换与范围限制

后台快照复用将一次切换中的快照构建从 5 次降至 2 次；对应后台操作样本从 694 ms 降至 297 ms。完整原生切换仍约 1.5 s。

进一步缩小操作返回值的同进程 A/B/A：完整回复就绪 1556 / 1493 ms，优化回复 1630 ms。以长会话标题出现且编辑器可编辑的第一帧计时，不以接口确认计时。该方案不通过收益验收，已撤除。

## 自动回归

已验证编辑器测量节点复用/清理、字体/宽度变更、自动增高、阅读/底部滚动、输入法、会话恢复和自定义工具生命周期。最终生产构建与 TypeScript 检查通过；Node 22 的 8 项后端回归、23 项界面回归全部通过。不声称全仓库测试通过，不以纯浏览器测试替代原生测试。
