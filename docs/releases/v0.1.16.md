Pi Desktop v0.1.16，改进错误通知的显示、叠层和自动消失行为。

- **通知更简洁**：先显示简短原因、HTTP 状态码和重试进度，完整错误默认折叠，可展开或复制；长错误不再直接铺满通知卡片。
- **多张卡片叠放**：最新通知显示在前面，后方露出卡片边缘；可展开逐条查看和关闭，每次普通通知保留各自的完整详情。
- **未查看时自动消失**：每张卡片独立计时，8 秒后移除。鼠标悬停、键盘聚焦、展开通知或查看详情时暂停，结束查看后继续剩余时间。新通知不会重置旧通知的计时。
- **滚动条与主题一致**：详情区和展开列表采用细圆角滑块、透明轨道，并适配明暗主题与窄窗口。
- **重试提示及时清理**：同一次自动重试更新进度卡片；重试结束或切换会话后清理临时提示，后台通知回放也会清理已结束的重试状态。

生产构建、通知及会话管理定向源码测试、更新发布校验和 10 项通知界面用例通过。界面验证覆盖明暗主题、桌面与窄窗口、实际显示滚动条、展开与复制详情、独立关闭和自动消失计时；未执行完整浏览器回归或真实跨版本安装升级验证。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.16_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.16_macos-arm64.dmg` |

可在「设置 → 应用更新」检查并安装。`latest.json`、更新包及 `.sig` 用于应用内更新；`SHA256SUMS` 提供校验，`build-info.json` 记录构建提交。沿用现有更新签名密钥；尚未配置 Windows 正式代码签名、Apple 发行签名及公证。

安装包由 Windows x64、macOS Apple Silicon 工作流构建，并在两端成功后发布。
