Pi Desktop v0.1.7，修复长会话中输入框自动测高引发的重复整页布局。

- 输入框复用隔离的测量节点，先读取样式再写入测量内容，避免每个字符插入、删除隐藏节点造成整页重新布局。
- 宽度与字体观察器随编辑器挂载和清理，不再每次输入重建。保留自动增高、输入法、光标和会话滚动位置。
- 已关闭的内置工具详情按需挂载；自定义渲染器和交互控件保留生命周期。
- 会话变更复用最后一次已发布快照，减少重复构建历史数据。

原生 macOS 验证使用 Node 22.23.2、约 13 MB 的长会话副本和实际模型配置，未发送模型请求。旧测高逻辑逐键显示延迟为 176–188 毫秒；修复后单组 18 字逐键为 2–15 毫秒。另一次 156 字快速连续输入全部保留，按键事件时间戳至可见帧延迟中位数 10 毫秒、95 分位 22 毫秒、最大 25 毫秒。数值来自该测试环境，不代表所有设备。

生产构建、TypeScript 检查、8 项 Node 22 后端回归及 23 项界面回归通过。

仍存在的限制：该超长历史切换到可编辑状态约需 1.5 秒，后台刷新也仍有长帧。本版不宣称彻底消除切换或所有后台刷新卡顿。未将原生对照无明显收益的快照回复压缩方案纳入发布。

安装包：Windows x64 使用 `.exe`，macOS Apple Silicon 使用 `.dmg`；应用内也可通过「设置 → 应用更新」更新。
