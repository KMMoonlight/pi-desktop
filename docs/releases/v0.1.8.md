Pi Desktop v0.1.8，支持多会话并行运行，并修复运行期间的消息发送与编辑体验。包含 v0.1.7 的长会话输入性能优化。

- **多会话并行**：A 会话运行时可以切换到 B 查看历史或发送消息，A 会继续执行。会话的输出、草稿、附件、终端和停止操作相互独立；侧栏显示后台运行、完成未读及需要处理的提示。
- **运行中反向发送**：Cmd + Enter（也支持 Ctrl + Enter）执行与“运行中发送消息”设置相反的交付方式，普通 Enter 继续使用原设置。
- **原生编辑快捷键**：恢复文本输入框中的 Cmd + C、X、V、A、Z 和 Shift + Z，分别用于复制、剪切、粘贴、全选、撤销和重做。
- **排队消息立即执行**：排队卡片新增“立即执行”按钮。点击后将原消息转为调整方向，在当前工具调用结束后的下一个处理时机交付，不等待整轮任务结束；保留附件和其他排队消息，并防止重复提交。
- **发送准备预览**：已接收的消息立即显示在对话中，并标注“正在准备发送…”。认证、上下文准备或扩展处理较慢时，消息不会因输入框清空而暂时消失；正式接收后替换预览，不重复显示。此项不代表已解决所有模型提供商之间的兼容性问题。

生产构建、TypeScript 检查、25 项后端/发布清单测试及 23 项界面回归通过。验证覆盖会话并行与跨工作区切换、独立停止、后台提问与完成提示、延迟响应、删除和恢复、编辑快捷键、消息队列附件与重复点击、切换模型后的发送准备预览，以及进程退出和更新清单。已知的扩展终端焦点、设置按钮尺寸及部分旧剪贴板测试失败在未修改版本中也能复现，未将其计作本版修复。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.8_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.8_macos-arm64.dmg` |

可在「设置 → 应用更新」检查并安装新版。安装前请结束正在运行的任务；关闭应用会结束所有后台会话的运行。每个打开的会话使用独立后台进程，会增加内存占用。

沿用现有更新签名密钥。`latest.json`、`.sig` 和 macOS `.app.tar.gz` 用于应用内更新；`SHA256SUMS` 提供附件校验，`build-info.json` 记录实际构建提交。尚未配置 Windows 正式代码签名、Apple 发行签名及公证。
