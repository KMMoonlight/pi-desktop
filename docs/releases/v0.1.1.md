Pi Desktop 0.1.1 测试预发布版，提供 Windows x64 与 macOS Apple Silicon 安装包。

修复 macOS 打开应用后意外退出的问题：安装包现已包含后台所需的 `micromark-util-decode-string` 及其依赖。打包流程增加内置 Node.js、Pi SDK、PTY 和后台启动检查，缺失依赖会直接阻止生成安装包。

同时保留 v0.1.0 已发布的工作区管理、输入框滚动和布局改进。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.1_windows-x64-setup.exe` |
| macOS Apple Silicon（M 系列） | `Pi-Desktop_0.1.1_macos-arm64.dmg` |

安装包内置 Node.js 和 Pi SDK，无需单独安装 Node 或 Pi。下载适合设备的安装包，覆盖安装即可；现有设置与会话保存在应用目录之外。

这是测试预发布版本，尚未配置 Windows 正式代码签名、Apple 发行签名及公证。
