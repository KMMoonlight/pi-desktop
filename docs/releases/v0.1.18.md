Pi Desktop v0.1.18，修复浅色主题下代码块过暗、代码难以辨认的问题。

- **代码块跟随主题**：浅色模式使用浅米色背景，深色模式使用对应的深色背景，避免浅色主题的深色文字落在黑底上。
- **高亮和工具栏保持一致**：语法高亮沿用当前主题的颜色，复制按钮和分隔线也跟随主题切换。
- **现有对话直接生效**：更新并重启后，历史消息中的代码块也使用修复后的样式，无需重新生成回复。

生产构建、Markdown 界面回归和更新发布校验通过。Markdown 验证覆盖浅色和深色主题、不同窗口宽度、代码复制及重载后的内容保留；未执行完整浏览器回归或真实跨版本安装升级验证。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.18_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.18_macos-arm64.dmg` |

可在「设置 → 应用更新」检查并安装。`latest.json`、更新包及 `.sig` 用于应用内更新；`SHA256SUMS` 提供校验，`build-info.json` 记录构建提交。沿用现有更新签名密钥；尚未配置 Windows 正式代码签名、Apple 发行签名及公证。
