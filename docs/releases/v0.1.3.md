Pi Desktop v0.1.3，提供 Windows x64 与 macOS Apple Silicon 安装包。

本次更新加入应用内更新，并改善输入响应：

- 新增「设置 → 应用更新」，显示当前版本、检查结果、下载进度和更新说明。
- 启动时及每 6 小时检查新版本，默认自动下载，也可关闭自动下载后手动操作。
- 下载完成后提示安装；必须确认后才安装并重启，避免自动重启打断任务。
- 更新包使用专用签名验证；检查、下载或验证失败时保留当前版本，支持重试。
- 优化普通按键的即时显示，减少等待后端响应造成的输入延迟；保持删除、移动光标和后续输入的顺序。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.3_windows-x64-setup.exe` |
| macOS Apple Silicon（M 系列） | `Pi-Desktop_0.1.3_macos-arm64.dmg` |

**首次升级：v0.1.2 及更早版本不含更新模块，请手动安装一次 v0.1.3；之后的新版本可在应用内检查和下载。** 设置与会话保存在应用目录之外，覆盖安装会保留。

此版本作为稳定更新通道的起始版本。更新仍需要能够访问 GitHub，下载内容仅保留在当前进程中，退出后需重新下载。安装前请结束正在运行的任务并保存编辑。

更新包签名用于应用内更新验证，与操作系统代码签名不同。目前尚未配置 Windows 正式代码签名、Apple 发行签名及公证，系统可能显示未识别开发者提示。

`latest.json` 和 `.sig` 文件供更新器使用；macOS `.app.tar.gz` 是更新包，手动安装请选择 `.dmg`。`SHA256SUMS` 提供附件校验值，`build-info.json` 记录构建来源。

验证：更新相关单元测试、更新界面交互、输入响应定向测试、TypeScript 构建与 Rust 检查通过。编辑器完整回归中的 Alt+V 剪贴板用例在本机仍失败，已在未修改的 v0.1.2 源码上复现；本版本未修复该已有问题。
