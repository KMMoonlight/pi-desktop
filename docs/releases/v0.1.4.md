Pi Desktop v0.1.4，修复长草稿输入卡顿和会话自动滚动中断。

- 普通打字和中文输入不再逐字测量整段草稿的光标布局；导航、自定义编辑器和需要布局的扩展仍保留测量。
- 降低后台快照渲染优先级，避免隐藏设置页和未变化的草稿产生多余更新。
- 修复内容增长未触发尺寸通知时停留在旧位置的问题；内容折叠、替换后继续跟随到底部。
- 修复输入框尺寸更新与手动上翻交错时被拉回底部的问题，保留阅读位置。

同条件 Chromium 测试中，16,000 字草稿输入同一句话的耗时从 5.09 秒降至 1.85 秒。这是含输入间隔和采样开销的浏览器对照结果，不是原生 Mac 输入延迟测量。原生界面实测尚未完成。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.4_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.4_macos-arm64.dmg` |

v0.1.3 用户可在「设置 → 应用更新」检查、下载并确认安装。v0.1.2 及更早版本需手动安装一次。覆盖安装保留应用目录外的设置和会话；安装前请结束任务并保存编辑。

沿用现有更新签名密钥。`latest.json`、`.sig` 和 macOS `.app.tar.gz` 供更新器使用；手动安装请选择 `.exe` 或 `.dmg`。`SHA256SUMS` 提供附件校验，`build-info.json` 记录构建来源。

尚未配置 Windows 正式代码签名、Apple 发行签名及公证。已有 Alt+V 剪贴板、PageDown 和设置按钮几何测试问题不属于本次修复范围，已在原代码中复现。
