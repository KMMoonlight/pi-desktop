Pi Desktop v0.1.20，修复侧边栏加载圆环的旋转方式，并让运行中的思考过程默认保持一行。

- **思考过程默认一行**：运行时只显示一行「思考过程」，多段思考和后续流式片段不会自动展开全文。主动点击后可以查看完整内容，再次收起后继续保持一行；手动展开、收起状态不会被输入或流式更新覆盖。历史回复仍可手动展开查看。
- **加载圆环围绕自身中心旋转**：侧边栏运行提示改用固定尺寸的 CSS 圆环，保留现有的执行中、未读和需要处理提示。

生产构建、版本一致性与更新发布校验通过。Chromium、WebKit 共 20 项相关浏览器回归通过，覆盖浅色和深色主题、宽窄窗口、流式思考、手动展开收起、历史回复，以及圆环完整旋转与会话状态切换；另补验了 macOS 系统 WKWebView 的连续动画。未执行完整浏览器回归或真实跨版本安装升级验证。
