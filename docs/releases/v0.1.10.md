Pi Desktop v0.1.10，修复会话切换卡顿与 composer 光标偏移。

- **加快会话切换**：空闲的同工作区会话切换复用当前 worker，避免重复创建 PTY、SDK runtime 和扩展 UI。
- **保持后台任务隔离**：忙碌会话或存在并行后台会话时，继续使用独立 worker，不中断正在运行的任务。
- **减少切换前等待**：侧边栏直接传递目标工作区路径，跳过重复扫描全部历史文件。
- **修复 composer 光标偏移**：统一输入框的盒模型、字体、内边距和行高，让可见文字与 caret 使用同一定位基准。

验证覆盖 TypeScript 检查、生产构建和会话 worker 切换回归测试。
