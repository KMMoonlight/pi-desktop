Pi Desktop v0.1.5，修复大量历史消息和工具输出导致的输入卡顿。

- 输入时通过增量快照同步变化，避免反复传输、解析整段历史和附件；不会删除或截断会话内容。
- SDK 后台、原生桌面桥接和浏览器连接均支持增量同步，未变化的消息保持引用稳定，减少重复渲染。
- 会话切换和重新连接时恢复完整快照；检测到同步基线缺失时重新同步，避免内容错乱。

使用一份包含 771 条记录、406 条工具结果的长会话副本进行对照：输入同样 18 个字符的测试耗时从约 14 秒降至 1.87 秒。该结果包含输入间隔及等待时间，不是单次按键延迟。另已在隔离的 macOS 原生应用中加载相同历史，验证英文逐键输入、光标移动和中文粘贴。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.5_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.5_macos-arm64.dmg` |

v0.1.3 及以上用户可在「设置 → 应用更新」检查、下载并确认安装。v0.1.2 及更早版本需手动安装一次。覆盖安装保留应用目录外的设置和会话；安装前请结束任务并保存编辑，未发送的图片附件需另行保留。

沿用现有更新签名密钥。`latest.json`、`.sig` 和 macOS `.app.tar.gz` 供更新器使用；手动安装请选择 `.exe` 或 `.dmg`。`SHA256SUMS` 提供附件校验，`build-info.json` 记录构建来源。

尚未配置 Windows 正式代码签名、Apple 发行签名及公证。本次相关传输、输入和重连测试已通过；全量单元测试仍有 SDK 编辑器、工具管理及文件系统相关失败，不宣称全套测试通过。
