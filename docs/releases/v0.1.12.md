Pi Desktop v0.1.12，正式交付会话切换性能、即时加载页和工作区顺序修复。此前 v0.1.11 的终端功能更新不包含这些修复。

- **点击立即进入目标会话页**：侧边栏选中项和标题立即更新，首次打开时显示加载状态，完成后展示内容。加载失败可重试；连续点击时以最后选择的会话为准。
- **减少长会话切换卡顿**：复用最近三个会话的传输快照，减少完整历史重复传输和冗余状态更新。
- **按需展示旧历史**：长会话优先展示最新轮次，向上滚动时加载对应内容；“显示全部历史消息”可展开全部历史，便于全文查找。历史数据不会被删除或截断。
- **工作区顺序保持稳定**：打开已有工作区的会话不再把工作区移动到列表首位。
- 保留 v0.1.11 的多终端 Tab、链接跳转和折叠保留运行状态。

验证包含三个真实长会话副本的 macOS 原生切换与输入测试，以及加载状态、失败重试、连续切换、草稿恢复、完整历史访问、滚动和并行任务回归。首次历史加载仍需后台处理时间，页面会立即显示加载状态；不承诺所有环境和会话规模都具有相同耗时。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.12_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.12_macos-arm64.dmg` |

可在「设置 → 应用更新」检查并安装。`latest.json`、更新包及 `.sig` 用于应用内更新；`SHA256SUMS` 提供校验，`build-info.json` 记录构建提交。沿用现有更新签名密钥；尚未配置 Windows 正式代码签名、Apple 发行签名及公证。

验证边界：扩展终端综合测试仍在原有焦点步骤失败，已在 v0.1.11 原代码复现；本次不宣称全套终端测试通过。初始化快照合并实验未纳入本次发布。
