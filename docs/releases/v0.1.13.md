Pi Desktop v0.1.13，将 Pi SDK 从 1.0.0 升级到 1.2.0，并同步相关桌面行为。

- **执行状态更清楚**：标题栏显示执行、压缩、重试、等待确认/输入/登录、完成和失败状态。
- **保留工具执行耗时**：工具卡片显示实际耗时，重新打开会话后保留；codemode 显示执行中的 Elapsed 和完成后的 Took，并支持原生图片输出。
- **MCP 项目配置与 Pi 一致**：设置页展示继承的全局服务器，支持项目启停、工具可见性覆盖及恢复全局配置；原生管理器修改后自动刷新。
- **恢复中的工具正常折叠**：使用 Pi 的通用工具渲染器，未注册或未连接工具的输出保留折叠预览和逐条展开。
- **滚动和输出显示同步**：Fullscreen 下 Ctrl+Home/End 滚动主对话，自定义键位同样生效并保留编辑器光标；输出边距覆盖工具、Shell 和摘要。
- **授权链接可复制**：账号授权支持复制按钮及 Pi 的复制快捷键，保留手动回调草稿；成功、失败和取消反馈与登录流程一致。
- **自定义编辑器配色一致**：内嵌压缩提示使用编辑器边框或思考等级颜色，并显示正确的取消快捷键；修复 `ctrl++` 等符号键的桌面编码。
- **升级兼容处理**：自动迁移旧 Azure 配置到 `azure`，兼容新版主题 Schema、快捷键元数据和扩展启动事件；沿用 Pi 的模型目录与 MCP 登录生命周期。
- 包含 master 上新增的对话轮次导航栏，以及窄屏设置布局修复。

发布前完整源代码回归 **1,327/1,327 通过**；本轮最终相关浏览器组 **22/22 通过**，覆盖桌面和窄屏。验证包括 Pi 升级回归、MCP 配置与 OAuth、原生组件映射、工具显示、编辑器输入与剪贴板；类型检查、生产构建、SDK 导出审计及运行时校验通过。详细验证记录见仓库 `docs/pi-1.2.0-upgrade.md`。
