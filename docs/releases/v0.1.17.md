Pi Desktop v0.1.17，支持从自定义提供商的模型列表接口批量导入模型。

- **一键获取模型**：在「设置 → 模型与账号 → 添加自定义端点」填写 API 地址和 API Key 后，点击「从 API 获取模型」，再统一保存，无需逐个填写模型 ID。支持 OpenAI 兼容的 `/v1/models` 响应，也支持带自定义路径前缀的 API 地址。
- **保留已有配置**：重复获取时自动去重，保留已配置的显示名称、能力、token 限制和高级参数；获取失败或取消编辑不会改写已保存的端点。
- **大量模型便于管理**：模型超过 3 个时默认折叠配置，展开后仍可单独编辑；接口未返回的模型能力和 token 限制可按需调整。
- **沿用凭据配置**：支持 API Key、环境变量引用、自定义请求头和密钥命令；请求在本地后端完成，支持超时和退出取消，无需先打开工作区。

生产构建、模型发现与全局设置定向测试、3 项相关界面回归和更新发布校验通过。未执行完整浏览器回归或真实跨版本安装升级验证。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.17_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.17_macos-arm64.dmg` |

可在「设置 → 应用更新」检查并安装。`latest.json`、更新包及 `.sig` 用于应用内更新；`SHA256SUMS` 提供校验，`build-info.json` 记录构建提交。沿用现有更新签名密钥；尚未配置 Windows 正式代码签名、Apple 发行签名及公证。

安装包由 Windows x64、macOS Apple Silicon 工作流构建，并在两端成功后发布。
