Pi Desktop v0.1.6，继续改善任务运行期间的输入响应，并修正输入法组合开始前的按键拦截。

- 普通文字按键先交由系统输入法处理，再通过文本输入事件同步后台；避免在输入法尚未标记组合状态时抢先插入字母。新增回归在 v0.1.5 中复现 `ni` 变成 `nni`，本版可正确提交“你”。
- 避免迟到的按键释放确认覆盖正在组合的文字，保留快捷键、原始按键信息和后台同步顺序。
- 默认工作动画由前端播放，不再每 80 毫秒触发整段原生历史重绘；扩展编辑器和外部提供的终端仍保留原生动画。
- 缓存已完成的内置工具视图和未变化的 Markdown，减少长会话反复遍历、解析及渲染。主题、宽度、展开状态和内容变化时更新缓存；自定义渲染器继续按原有方式更新。
- 未变化的历史消息与工具组件不再随活动回复反复渲染。

已通过缓存/生命周期/原生组件相关的 35 项测试，以及输入法、迟到确认、按键阶段、大历史运行中输入等回归。工具自定义展开测试仍有既有失败，已在 v0.1.5 对照中复现。本次不以测试耗时替代所有设备、输入法下的实际体验验证。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.6_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.6_macos-arm64.dmg` |

v0.1.3 及以上用户可在「设置 → 应用更新」检查、下载并确认安装。覆盖安装保留应用目录外的设置和会话；安装前请结束任务并保存编辑，未发送的图片附件需另行保留。

沿用现有更新签名密钥。`latest.json`、`.sig` 和 macOS `.app.tar.gz` 供更新器使用；手动安装请选择 `.exe` 或 `.dmg`。`SHA256SUMS` 提供附件校验，`build-info.json` 记录构建来源。尚未配置 Windows 正式代码签名、Apple 发行签名及公证。
