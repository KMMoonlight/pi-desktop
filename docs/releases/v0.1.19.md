Pi Desktop v0.1.19，完善自定义模型信息导入，修复回复计时与侧边栏状态，并在输入框下方显示当前 Git 分支。

- **导入更完整的模型信息**：从 `/models` 获取名称、上下文长度、最大输出、思考档位、工具与视觉能力，兼容 SDK 原生字段及常见 OpenRouter 字段。刷新会补齐缺少的信息，并保留已有配置及自定义思考档位映射；工具能力区分「支持」「不支持」「未声明」。详见[模型导入字段](https://github.com/KMMoonlight/pi-desktop/blob/v0.1.19/docs/provider-models.md)。
- **回复耗时持续更新**：执行命令或等待工具时继续计时，完成或中止后保留最终耗时；发送下一条消息不会改动上一条回复的耗时。长耗时自动显示为分、小时。
- **执行过程更清晰**：运行时展示当前思考或工具步骤，完成后将执行过程收起，保留回复摘要与输出统计。
- **侧边栏更稳定**：加载图标绕自身中心旋转；工作区展开状态在切换、搜索和重新加载后保留；手动修改文件夹路径时，较早的目录加载结果不会覆盖新输入。
- **显示当前 Git 分支**：Git 工作区在输入框下方显示分支，随工作区及分支切换更新；分离 HEAD 状态使用对应语言显示。

生产构建、模型导入与思考档位、耗时格式与时钟状态、消息提交时序、更新发布校验，以及相关浏览器回归通过。浏览器验证覆盖模型刷新与保存、命令执行期间计时和结束后冻结、回复过程展示、工作区展开状态、文件夹选择及 Git 分支切换；未执行完整浏览器回归或真实跨版本安装升级验证。
