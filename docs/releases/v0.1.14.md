Pi Desktop v0.1.14，新增关闭窗口后驻留托盘的功能。

- **关闭后继续运行**：点击窗口关闭按钮后隐藏主窗口，保留当前会话、未发送草稿及后台任务。
- **从托盘恢复窗口**：托盘菜单提供「打开 Pi Desktop」，恢复原窗口并取消最小化。Windows 支持单击或双击托盘图标；macOS 使用菜单栏托盘，也可从 Dock 恢复窗口。
- **明确退出入口**：选择托盘菜单的「退出 Pi Desktop」后，等待 SDK 正常清理再退出。macOS 应用菜单退出和 SDK 编辑器退出沿用同一清理流程，重复退出请求只触发一次清理。
- **减少误触刷新**：屏蔽 WebView 的原生浏览器右键菜单，包括其中的刷新入口。

类型检查、生产构建、Rust 测试和 SDK 退出回归通过。macOS 原生窗口生命周期验证覆盖托盘创建、隐藏后会话保留、恢复窗口、取消最小化，以及等待一个 4.5 秒的异步清理钩子。新增 Windows 原生 `--tray` 回归流程；本轮未在 Windows 实机上执行，macOS 托盘菜单的鼠标点击尚未实测。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.14_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.14_macos-arm64.dmg` |

可在「设置 → 应用更新」检查并安装。`latest.json`、更新包及 `.sig` 用于应用内更新；`SHA256SUMS` 提供校验，`build-info.json` 记录构建提交。沿用现有更新签名密钥；尚未配置 Windows 正式代码签名、Apple 发行签名及公证。

新安装包由 Windows x64、macOS Apple Silicon 工作流构建，并在两端成功后发布。
