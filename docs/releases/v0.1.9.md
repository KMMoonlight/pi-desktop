Pi Desktop v0.1.9，修复关闭应用后工具选择与显示偏好丢失的问题。

- **记住工具选择**：会话检查器中手动启用或禁用的工具按工作区保存，重新打开应用或新建会话后恢复。
- **记住思考展示**：检查器中的“展开思考”会保存到配置，避免重启时被旧设置覆盖。
- **记住详细视图**：“展开工具输出”持久保存，会话菜单的“详细”视图在重启或页面重载后正确恢复。
- **恢复全局外观**：未选择工作区时，思考展示与颜色模式从保存的配置恢复，支持“跟随系统”，不再显示旧缓存。

回归验证覆盖工具启用与禁用、工作区隔离、会话恢复、工具输出展开、页面重载以及无工作区时的外观配置。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.9_windows-x64-setup.exe` |
| macOS Apple Silicon | `Pi-Desktop_0.1.9_macos-arm64.dmg` |

可在「设置 → 应用更新」检查并安装新版。安装前请结束正在运行的任务；关闭应用会结束后台会话的运行。

沿用现有更新签名密钥。`latest.json`、`.sig` 和 macOS `.app.tar.gz` 用于应用内更新；`SHA256SUMS` 提供附件校验，`build-info.json` 记录实际构建提交。尚未配置 Windows 正式代码签名、Apple 发行签名及公证。
