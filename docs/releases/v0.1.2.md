Pi Desktop v0.1.2 测试预发布版，提供 Windows x64 与 macOS Apple Silicon 安装包。

本次更新集中改善长会话输入、输出跟随和聊天界面的交互体验：

- 减少输入时未变化的历史消息重绘，改善长会话输入卡顿；修复迟到的按键响应覆盖新光标位置的问题。
- 修复自动滚动中断、切换会话后不跟随，以及已到底部仍显示“回到最新消息”按钮的问题；手动上翻时保留阅读位置。
- 代码修改采用紧凑文件卡片，提供相对路径、行号、增删高亮、复制 diff 和源文件跳转。
- 收紧用户消息列表与附件间距，上下留白及文字与图片间隔统一为 8px。
- 重做排队消息卡片，提供明确的“取回编辑”按钮，保留已有草稿和当前任务。
- 会话名称前显示运行图标；完成未读时显示蓝点，查看最新消息后消失，未读状态保存在本机。
- 修复组件更新时重复出现 `Desktop component hit path is no longer available` 的错误。
- 任务执行期间隐藏删除会话按钮、禁用思考等级修改，结束后恢复。
- 默认加载提示改为基于 [pi.dev 官方标志](https://pi.dev/) 的彩色方块掉落动画，支持减少动态效果设置。

保留 v0.1.1 的 macOS 启动修复与打包运行时验证。仅提供 Windows x64 和 Apple Silicon 安装包，不再构建 Intel Mac 版本。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.2_windows-x64-setup.exe` |
| macOS Apple Silicon（M 系列） | `Pi-Desktop_0.1.2_macos-arm64.dmg` |

安装包内置 Node.js 和 Pi SDK，覆盖安装即可，设置与会话保存在应用目录之外。附件 `SHA256SUMS` 提供校验值，`build-info.json` 记录构建来源和验证结果。

已知限制：空输入框的视觉光标偏移尚未稳定复现；现有自定义工具展开的两项 `tool-display` 界面测试仍失败，桌面用例已在修改前版本复现。修复范围覆盖已复现的异步光标回跳。

这是测试预发布版本，尚未配置 Windows 正式代码签名、Apple 发行签名及公证。
