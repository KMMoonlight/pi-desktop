Pi Desktop 0.1.2 测试预发布版，提供 Windows x64 与 macOS Apple Silicon 安装包。

修复思考、生成回复期间侧边栏会话删除按钮意外出现的问题。任务运行时隐藏会话删除按钮，任务结束或停止后恢复鼠标悬停显示。

保留 v0.1.1 的 macOS 启动修复和安装包运行时依赖检查。

验证：TypeScript 检查、生产构建及 5 项 UI 回归测试通过，覆盖浅色/深色主题下思考期间隐藏、停止后恢复、会话删除确认和不同窗口宽度的工作状态指示器。

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `Pi-Desktop_0.1.2_windows-x64-setup.exe` |
| macOS Apple Silicon（M 系列） | `Pi-Desktop_0.1.2_macos-arm64.dmg` |

安装包内置 Node.js 和 Pi SDK，无需单独安装 Node 或 Pi。下载适合设备的安装包，覆盖安装即可；现有设置与会话保存在应用目录之外。

这是测试预发布版本，尚未配置 Windows 正式代码签名、Apple 发行签名及公证。
