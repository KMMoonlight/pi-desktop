# 整体布局与样式复查（2026-10-07）

后续复查又确认了工具栏继承分割线和按钮类名未实际生效两项遗漏，
本页原有结论仅代表当时的检查范围。最新修复、国际化和补验依据见
[界面国际化与遗漏复查](interface-localization.md)。

本轮依据既有 `Design.md`、`DESIGN.application.md` 和官方 Harness
运行界面来源复查实际渲染。以完整页面的层级、对齐、控件归属和操作可达性
为依据，不以功能测试通过或页面没有横向溢出代替视觉验收。

## 已修复的原因与表现

| 问题 | 原因 | 修复与验收依据 |
| --- | --- | --- |
| 输入区的工作区选择器下沉，工具栏多出留白 | 复用了旧侧边栏的类名，继承顶部 20px 边距和外层内边距 | 使用独立的 composer 控件类，移除无用旧规则；选择器与上下文按钮的中心对齐，桌面还与发送区对齐；保留窄窗口宽度上限 |
| MCP 表单的字段布局混用两列偏好设置和上方标签 | 只重置了嵌套字段，没有重置直接字段；嵌套字段间距仍为零 | 所有集成表单字段使用统一的上方标签和 16px 字段间距；文本框、下拉框都有输入边界 |
| 新增 MCP/包时空状态仍占据表单上方 | 空列表展示未区分正在编辑 | 空列表添加时隐藏空状态；打开后先展示表单标题并聚焦首字段；取消回到添加入口 |
| 表单取消独占一整行，安装操作散落 | 操作没有明确的标题和主操作区域 | 标题右侧放取消；主操作沿表单右边对齐；移除扩展包页面重复标题 |
| 模型配置范围占一整行 | 范围选择器直接放在垂直设置组内 | 标题与范围构成同一行，窄窗口允许自然换行；统一嵌套组标题字体与边距 |
| 端点编辑时同时出现“保存端点”和“保存设置” | 页面偏好设置 footer 未识别端点编辑/确认状态 | 编辑或删除确认期间隐藏偏好设置 footer，关闭后恢复；保留原偏好设置草稿和独立配置写入 |
| 保留 MCP 草稿后新增扩展包时首字段没有焦点 | 本轮合并的焦点逻辑优先匹配 MCP 状态，没有检查当前分类 | 只聚焦当前分类的表单，切回后保留 MCP 草稿并展示表单首字段；新增跨分类流程回归检查 |

SDK 的原始消息与工具渲染器、扩展回调、目录选择、配置保存和 xterm.js
继续使用原有路径。本轮没有增加 SDK、终端协议或平台支持范围。

## 成组验证与状态保护

工作流按大类运行，失败后只补跑受影响的一组。首轮表单标题对齐检查
捕获了遗留 5px 标题边距，随后修正；新增内容采集脚本也修正了侧栏关闭
时打开设置的步骤，以及主题切换方式。

- `workflows.log`：菜单、提供商、工作区、侧栏、设置和遗漏修复组。
- `content-workflows.log`：原有桌面会话/终端、认证和扩展键盘流程。
- `affected-final.log`：修复标题后，设置表单/会话结构与内容组通过。
- `content-verified.log`：使用 SDK 真实明暗主题的内容采集通过。
- `review-final.log`：最终内容、结构、代码复制和 Git diff 组。
- `settings-workflow-final.log`：最后的跨分类表单焦点、草稿和设置滚动组。
- `live-final.log`、`settings-final.log`：无页面横向溢出、无页面错误，
  当前 cwd、会话 ID、消息、草稿、注册工作区和全局/项目设置保持原样。

用户预览保持在 1451，当前工作区为 `C:\Code\pi-agnet-desktop`，

临时测试目录与后端，没有往 live 会话写入测试内容。
